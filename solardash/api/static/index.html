Diagnostics

Chargeverter GC

The Chargeverter cannot be polled. It is a Modbus master that asks "the battery" for SOC every half second (01 03 00 13 00 11 at 9600 baud on RJ45 pins 1/2). solardash can listen to that bus, and in emulate mode answer it with the real pack data so the charger stops showing LOST and can start/stop the generator on SOC.

Derived output

Chargeverter DC power = (sum of pack currents × voltage from the BMSs) − (inverter battery charge − discharge power). Below the configured threshold it is reported as 0.

Inverter settings

Values are read from the inverter's holding registers. Writes are range-checked, applied with read-modify-write for bit fields, and read back for verification. They are only enabled when inverter.allow_writes: true is set in the config file.
